인스타그램 DM & 댓글 응답 가이드

기본 원칙​

DM 응답​

  • 톤: 채널톡과 유사하게 친근하지만 전문적
  • 응답 시간: 영업시간 내 1시간 이내
  • 길이: 최대 2-3문장
  • 링크: 자사몰 또는 퍼블릭 콘텐츠 페이지

예시:

안녕하세요 😊
사이즈 문의는 DM으로는 어려워서,
채널톡에서 자세히 도와드릴게요: [채널톡 링크]

댓글 응답​

  • 공개성 주의: 모든 댓글은 다른 고객도 볼 수 있음
  • 셀럽 언급 금지: DM보다 더 엄격하게 적용
  • 개인정보 보호: 주문번호, 개인정보 절대 언급 금지
  • 긍정적 톤: 부정 댓글에도 정중하게

예시:

✅ 문의 주셔서 감사합니다!
DM으로 자세히 안내드릴게요 😊

DM 응답 상황별 템플릿​

사이즈 문의 DM​

고객: 이거 사이즈 어떻게 골라요?

CS:

키와 몸무게 알려주시면 추천드릴게요!
사이즈 차트: [상세페이지 링크]

재입고 문의 DM​

고객: 이거 재입고 되나요?

CS:

재입고 알림 신청 도와드릴게요!
이메일 주소 남겨주시면 입고 시 바로 연락드리겠습니다 ✅

협업/PR 문의 DM​

고객: 협업 문의드립니다

CS:

안녕하세요! 협업 관련 문의는
2000archives.official@gmail.com 으로 보내주시면
담당자가 확인 후 회신드리겠습니다 ✅

댓글 유형별 대응​

칭찬 댓글​

감사합니다! 앞으로도 좋은 제품으로 보답하겠습니다 ✅

질문 댓글 (사이즈, 재입고 등)​

DM으로 자세히 안내드릴게요 😊

클레임 댓글 (공개 불만)​

불편을 드려 죄송합니다 🙏
DM 드렸으니 확인 부탁드려요!

주의: 클레임은 공개 댓글에서 절대 디테일을 논의하지 않음. 반드시 DM으로 유도.

악성 댓글​

  • 욕설/비방: 숨기기 처리 + 스크린샷 보관
  • 반복적 악성: 차단 + Slack #2000archives-general 보고
  • 법적 위협: 즉시 관리자 에스컬레이션

스토리 멘션 대응​

유형대응
제품 착용 포스팅♥️ 반응 + "감사합니다" DM
제품 불만 포스팅DM으로 사과 + CS 연결
셀럽 관련 태그반응 없음 (셀럽 연관 금지)

구매 유도 금지​

인스타그램에서는 구매를 강요하거나 유도하지 않습니다.

❌ "지금 구매하시면 할인돼요!" ✅ "자세한 정보는 프로필 링크에서 확인하세요 ✅"

채널톡 유도​

복잡한 문의는 채널톡으로 유도:

자세한 상담은 채널톡에서 도와드릴게요!
[채널톡 링크] 또는 자사몰 우측 하단 채팅 버튼 클릭 😊
