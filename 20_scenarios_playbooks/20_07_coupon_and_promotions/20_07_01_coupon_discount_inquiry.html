쿠폰/할인 코드 문의

1. 상황 설명​

고객이 쿠폰 사용 방법, 할인 적용 안 됨, 쿠폰 만료, 프로모션 관련 문의를 합니다.

주요 패턴:

  • "쿠폰이 있는데 적용이 안 돼요"
  • "할인코드 어디에 입력하나요?"
  • "쿠폰이 만료됐는데 다시 받을 수 있나요?"
  • "프로모션 언제까지인가요?"
  • "생일 쿠폰은 어떻게 받나요?"
  • "쿠폰 2개 같이 쓸 수 있나요?"
  • "세일 상품에도 쿠폰 적용 되나요?"

2. 에이전트 행동 플로우​

  1. 문의 유형 파악

    • 고객명 확인 ({{고객명}} 고객님 호칭 사용)
    • 쿠폰 적용 오류: 기술적 문제인지, 사용 조건 미충족인지 확인
    • 쿠폰 발급 요청: 유자격 여부 확인
    • 프로모션 정보: 현재 진행 중인 프로모션 확인
    • 필요 시 최근 주문 이력 확인 ({{최근_구매_이력}}) 후 가장 유리한 적용 방식 제안

  2. 쿠폰 적용 안 됨 — 원인 체크리스트

    • 최소 주문 금액 미달 (일반적으로 3만원 이상)
    • 세일 상품 제외 쿠폰인데 세일 상품 구매
    • 유효 기간 만료
    • 이미 사용한 쿠폰 (1회 주문당 1개)
    • 프로모션 할인과 쿠폰 중복 사용 불가

  3. 쿠폰 유형별 안내

쿠폰 유형발급 조건할인유효 기간
신규가입회원 가입 시 자동5,000원30일
생일생일 월 1일 자동10% (최대 1만원)생일 월 말일
VIP분기별 자동15% (최대 3만원)60일
시즌 할인프로모션 기간10-20%프로모션 종료일
보상불량/지연/오배송3,000-10,000원90일
  1. 중복 사용 규칙 안내
    • 쿠폰 + 쿠폰: 불가 (1회 주문 1개)
    • 프로모션 할인 + 쿠폰: 불가
    • 쿠폰 + 포인트: 가능
    • 프로모션 할인 + 포인트: 가능

3. 응답 템플릿​

3a. 쿠폰 적용 안 됨 (ChannelTalk)​

"{{고객명}} 고객님, 쿠폰이 안 먹어서 당황하셨죠. 확인해보니 [원인] 때문이고, [해결 방법]으로 바로 적용 가능해요. 필요하시면 {{최근_구매_이력}} 기준으로 더 유리한 쿠폰도 같이 봐드릴게요."

3b. 쿠폰 만료 문의 (ChannelTalk)​

"{{고객명}} 고객님, 만료된 쿠폰은 정책상 재발급이 어려워요. 대신 지금 주문 기준으로 적용 가능한 프로모션을 바로 정리해드릴게요."

3c. 쿠폰 중복 사용 (ChannelTalk)​

"{{고객명}} 고객님, 쿠폰은 1회 주문에 1개만 사용 가능해요. 고객님 주문({{최근_구매_이력}}) 기준으로는 [더 유리한 쿠폰]이 가장 유리합니다."

3d. 이메일 응답​

안녕하세요, 2000 아카이브입니다.

쿠폰 관련 문의 주신 내용 확인했습니다.
{{고객명}} 고객님의 최근 주문 이력({{최근_구매_이력}})을 함께 확인해 가장 유리한 적용 기준으로 안내드립니다.

[원인/안내 내용]

추가 궁금하신 사항 있으시면 언제든 문의 부탁드립니다.

4. 에스컬레이션 조건​

VIP 고객 쿠폰 만료 재발급 요청매니저 승인 필요
10,000원 이상 쿠폰 발급 요청매니저 승인 필수

5. 주의 사항​

  • 프로모션 종료 후 취소 시 재주문은 정가 적용 (프로모션 복구 불가)
  • 반품 시 사용한 쿠폰은 소멸 (복구 불가)
  • 주문 취소(발송 전) 시 쿠폰 자동 복구 (유효 기간 내)
  • 부분 반품 시 쿠폰 할인 재계산 필요 (상세: 10_06_coupon_point_promo_policy.md)
