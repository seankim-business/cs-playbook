사이즈 및 핏 문의

1. 상황 설명​

고객이 상품의 사이즈나 핏에 대해 문의합니다. 키, 몸무게, 체형 등의 정보를 제공하며 어떤 사이즈를 선택해야 할지 질문합니다.

2000 Archives 사이즈 체계: 00 / 0 / 1 / 2 (S/M/L/XL 체계가 아님)

주요 패턴:

  • "165cm 55kg인데 어떤 사이즈가 맞을까요?"
  • "평소에 M 입는데 NAPOLEON JACKET은 어떤 사이즈인가요?"
  • "어깨가 넓은 편인데 VELYN CORSET TOP 괜찮을까요?"
  • "SNYDER WIDE DENIM 오버핏인가요? 사이즈 0이랑 1 중에 고민이에요"

2. 에이전트 행동 플로우​

  1. 상품 식별

    • 고객이 문의한 상품 코드 또는 상품명 확인
    • 30_products/ 폴더에서 해당 상품의 사이즈 차트 조회
    • Cafe24 상품 상세 또는 무신사/29CM 상품 페이지 참조

  2. 사이즈 차트 분석

    • 실측 사이즈 데이터 확인 (총장, 어깨너비, 가슴단면, 소매길이 등)
    • 상품의 핏 특성 파악 (오버핏/레귤러/슬림)
    • 2000 Archives 사이즈 체계(00/0/1/2) 기준으로 안내

  3. 체형 기반 추천

    • 35_kb_material_and_care/35_02_body_shape_recommendations.md에서 키/몸무게 범위별 추천 사이즈 매칭
    • 고객 제공 정보와 비교하여 적합 사이즈 도출

  4. 응답 작성

    • 추천 사이즈 명시 (예: "고객님 체형이라면 사이즈 0 추천드립니다")
    • 실측 수치 함께 제공
    • 핏 특성 간단히 설명 (예: "이 제품은 오버핏으로 여유 있게 떨어집니다")
    • 절대 금지: "마르신 편", "통통하신 편" 등 체형 평가 표현

  5. 추가 안내

    • 자사몰/무신사/29CM 상세 페이지 사이즈 가이드 링크 제공
    • 불확실할 경우 교환 정책 안내

3. 응답 템플릿​

채널톡 버전​

📏 사이즈 가이드: {{상품_링크}}

예시 (NAPOLEON JACKET 사이즈 문의):

고객님 체형(165cm 55kg)이라면 사이즈 0 추천드려요! 실측 기준 총장 68cm, 가슴단면 54cm예요. NAPOLEON JACKET은 구조적인 숄더 라인의 레귤러핏으로, 사이즈 0이 깔끔하게 떨어집니다. 자세한 사이즈표는 상세페이지에서 확인 가능해요 😊

📏 사이즈 가이드: https://2000archives.com/product/napoleon-jacket

예시 (SNYDER WIDE DENIM 사이즈 문의):

고객님 체형(170cm 60kg)이라면 사이즈 1 추천드려요! SNYDER WIDE DENIM은 와이드핏으로 여유 있게 떨어지며, 실측 기준 허리 36cm, 총장 108cm예요. 편하게 입으시려면 사이즈 1, 핏감을 살리시려면 사이즈 0도 가능합니다 😊

📏 사이즈 가이드: https://2000archives.com/product/snyder-wide-denim

4. 주의사항​

절대 금지 표현​

  • "마르신 편", "통통하신 편", "작으신 편" 등 체형에 대한 평가적 표현
  • "보통 체형", "일반 체형" (기준이 모호함)
  • "뚱뚱해서", "살이 찌셔서" 등 부정적 체형 언급
  • S/M/L/XL 사이즈 표기 (2000 Archives는 00/0/1/2 체계 사용)

권장 표현​

  • "고객님의 체형 정보 기준으로"
  • "제공해주신 키와 몸무게를 참고하면"
  • "실측 사이즈와 비교하시면"
  • "사이즈 0 또는 사이즈 1 중에서"

사이즈 체계 변환 참고​

2000 Archives일반 사이즈 참고비고
00XS~S가장 작은 사이즈
0S~M기본 사이즈
1M~L중간~큰 사이즈
2L~XL가장 큰 사이즈

추가 주의사항​

  1. 수치 기반 응답: 감정이나 주관적 판단 배제, 오직 실측 데이터 기반
  2. 핏 특성 명시: 오버핏/레귤러/슬림 등 객관적 핏 정보 제공
  3. 교환 정책 안내: 사이즈 불확실 시 교환 가능 정책 함께 안내
  4. 사진 제공 유도: 모델 착용 사진이 있다면 참고할 수 있도록 링크 제공
  5. 개인차 명시: "개인의 선호도에 따라 다를 수 있습니다" 등 면책 문구
  6. 채널별 시스템: 자사몰(Cafe24), 무신사(파트너센터), 29CM(판매자센터)별 사이즈 표기 확인
