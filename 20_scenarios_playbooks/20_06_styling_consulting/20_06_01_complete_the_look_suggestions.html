코디 추천 (Complete the Look)

1. 상황 설명​

고객이 특정 상품과 어울리는 다른 아이템이나 완성된 룩을 문의합니다. 스타일링 제안을 통해 추가 구매를 유도할 수 있는 기회입니다.

2000 Archives 사이즈 체계: 00 / 0 / 1 / 2

주요 패턴:

  • "NAPOLEON JACKET이랑 어울리는 바지 추천해주세요"
  • "SNYDER WIDE DENIM으로 어떻게 코디하면 좋을까요?"
  • "VELYN CORSET TOP 완성된 룩으로 보고 싶어요"
  • "BALLOON SKIRT [미확인] 같이 입을 만한 아이템 있나요?"

2. 에이전트 행동 플로우​

  1. 상품 식별

    • 고객이 언급한 상품 확인
    • 30_products/ 폴더에서 해당 상품 정보 조회 (사이즈, 소재, 핏)

  2. 코디 룩 조회

    • 26_styling_upsell_cross_sell/26_02_cross_sell_rules/ 에서 해당 상품의 추천 코디 조회
    • 시즌별/스타일별 매칭 아이템 확인

  3. 퍼블릭 페이지 확인

    • 40_public_content_links/40_02_lookbook_and_shop_the_look_pages.md에서 퍼블릭 룩북 링크 확인
    • 셀럽 이름 절대 금지 원칙 확인 (26_01_celeb_influencer_looks는 내부 참조용)

  4. 재고 확인

    • Cafe24 어드민 + 셀릭 ERP에서 추천 아이템 재고 확인
    • 주의: 셀릭 ERP 전환 중 상품코드 매칭 오류 가능 -- 수동 크로스체크
    • 재고 있는 상품만 추천

  5. 응답 작성

    • 추천 아이템 목록 (이름 + 링크)
    • 스타일링 팁 간단히 제공
    • 셀럽 이름 절대 언급 금지
    • 퍼블릭 페이지 링크만 제공

  6. 추가 제안

    • 룩북/Shop the Look 페이지 링크
    • 유사 룩 제안 (해당 시)

4. 주의사항​

절대 금지 사항 (CRITICAL)​

금지 행동이유
셀럽 이름 언급초상권 침해 가능 -- 26_01_celeb_influencer_looks는 내부 참조용
내부 코드/ERP 정보 노출보안
품절 상품 추천고객 실망
과도한 추천 (5개 이상)선택 혼란
S/M/L/XL 표기2000 Archives는 00/0/1/2 체계

셀럽 이름 절대 금지 예시:

  • "OOO 배우가 입은 룩입니다" -- 금지
  • "XX가 착용한 코디예요" -- 금지
  • "스타일링 가이드에서 확인하세요" (퍼블릭 링크만) -- 허용

권장 표현​

  • "이 아이템과 잘 어울립니다"
  • "시크한/캐주얼한/페미닌한 스타일 연출 가능합니다"
  • "완성된 룩은 링크에서 확인하세요"

추가 주의사항​

  1. 재고 확인 필수: Cafe24 + 셀릭 ERP 크로스체크 후 재고 있는 상품만 추천
  2. 가격대 다양화: 다양한 가격대 상품 믹스하여 선택권 부여
  3. 스타일 명확히: "시크", "캐주얼", "페미닌" 등 구체적 스타일 명시
  4. 퍼블릭 링크만: 내부 문서/셀럽 정보 절대 노출 금지
  5. 사이즈 안내: 00/0/1/2 체계로 사이즈 범위 안내

코디 추천 원칙​
