색상 차이 이슈

1. 상황 설명​

고객이 수령한 상품의 색상이 온라인 쇼핑몰 사진과 다르다고 불만을 제기합니다. 모니터 환경에 따른 색상 차이가 대부분이지만, 실제 촬영 오류나 조명 차이도 있을 수 있습니다.

주요 패턴:

  • "SNYDER WIDE DENIM 블랙이라고 했는데 실제로 보니까 차콜 같아요"
  • "NAPOLEON JACKET 화면에서는 네이비였는데 실물은 검은색 같아요"
  • "VELYN CORSET TOP 색감이 기대와 달라서 실망했어요"
  • "사진이랑 색이 완전 달라요"

2. 에이전트 행동 플로우​

  1. 상품 및 색상 확인

    • 주문한 상품 및 색상 옵션 확인 (Cafe24 어드민/무신사/29CM)
    • 30_products/active/ 폴더에서 해당 색상의 공식 설명 조회

  2. 색상 차이 원인 파악

    • 모니터 환경: 대부분의 경우, 화면 밝기/색온도 차이로 인한 착시
    • 조명 차이: 촬영 시 조명 vs 실내/실외 조명 차이
    • 실제 오류: 상품 페이지 사진이 잘못 업로드된 경우 (드물음)

  3. 참고 자료 제공

    • 상품 상세 페이지의 "색상 안내" 섹션 링크 제공
    • 룩북/실물 컷 제공 (있을 경우)

  4. 응답 작성

    • 모니터 환경 차이 설명 (기술적 한계 인정)
    • 공식 색상 설명 제공
    • 불만족 시 반품 가능 안내 (7일 이내, 단순 변심 배송비 고객 부담)

  5. 반품 처리 (고객이 원할 시)

    • 교환/반품/환불 정책에 따라 반품 절차 안내
    • 배송비 안내 (단순 변심: 편도 3,000원)

4. 주의사항​

절대 금지 표현​

  • "사진이 원래 그래요" -- 책임 회피
  • "색상 차이는 당연한 거예요" -- 고객 불만 무시
  • "화면 설정 문제예요" -- 고객 책임 전가

권장 표현​

  • "모니터 환경에 따라 색상이 다르게 보일 수 있습니다"
  • "조명에 따라 색감이 달라질 수 있습니다"
  • "불만족 시 반품 가능합니다"

추가 주의사항​

  1. 색상 설명 정확히: 구체적 설명 제공 (예: "워싱 가공된 블랙으로 약간의 차콜 톤이 있습니다")
  2. 참고 자료 제공: 실물 컷, 다양한 조명 사진 링크 제공
  3. 반품 배송비 명시: 단순 변심은 고객 부담 (3,000원) 명확히 안내
  4. 기술적 한계 인정: 모니터 차이는 온라인 쇼핑의 한계임을 솔직히 설명
  5. 공감 표현: "기대와 달라 실망스러우셨을 것 같아 죄송합니다"
