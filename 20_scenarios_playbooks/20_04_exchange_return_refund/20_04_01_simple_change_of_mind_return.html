단순 변심 반품

1. 상황 설명​

고객이 상품에 하자가 없지만, 개인적인 사유(마음이 바뀜, 필요 없어짐, 다른 상품 구매 등)로 반품을 요청합니다.

주요 패턴:

  • "NAPOLEON JACKET 그냥 마음이 바뀌었어요, 반품하고 싶어요"
  • "SNYDER WIDE DENIM 다른 거 샀어서 필요 없어요"
  • "VELYN CORSET TOP 생각보다 마음에 안 들어요"
  • "환불 받을 수 있나요?"

2. 에이전트 행동 플로우 (Notion SOP PROC-B-004 Step 3 기반)​

Step 3: 환불 처리 프로세스​

  1. 사유 확인

    • 주문번호 확인 (Cafe24 어드민/무신사/29CM)
    • 반품 사유 확인 (단순 변심 여부)

  2. 반품 조건 확인

    • 수령일: 7일 이내인지 확인
    • 택/라벨: 제거 여부 확인 (미제거 필수)
    • 착용 흔적: 없는지 확인
    • 세탁 여부: 세탁 안 했는지 확인

  3. 회수 접수

    • 자사몰: Cafe24 어드민에서 반품 접수 → 패스트박스 3PL 회수 요청
    • 무신사: 무신사 파트너센터에서 반품 승인 → 회수 처리
    • 29CM: 29CM 판매자센터에서 반품 승인 → 회수 처리
    • 택배 수거 신청 (편도 배송비 3,000원 고객 부담)

  4. 검수

    • 패스트박스 3PL에서 회수 상품 검수
    • 택/라벨 상태, 착용 흔적, 세탁 여부 확인
    • 검수 통과 시 환불 처리 진행

  5. 환불 처리

    • Cafe24 어드민에서 환불 처리 (결제 금액 - 배송비 3,000원)
    • 환불 소요: 3-5 영업일
    • 쿠폰/적립금 사용 시 자동 복구

4. 주의사항​

절대 금지 표현​

  • "왜 반품하시나요?" -- 고객 의사에 이의 제기 금지
  • "한 번 입어보셨죠?" -- 착용 흔적 없으면 추궁 금지
  • "환불 안 됩니다" (대신 "반품이 어렵습니다" + 대안 제시)

권장 표현​

  • "반품 가능합니다"
  • "배송비는 편도 3,000원 부담 부탁드립니다"
  • "조건 미충족으로 반품이 어렵습니다만, 교환은 가능합니다"

추가 주의사항​

  1. 반품 조건 명확히: 7일 이내, 택/라벨 미제거, 착용 흔적 없음
  2. 배송비 명시: 단순 변심은 고객 부담 3,000원 (편도)
  3. 환불 금액 정확히: 결제 금액 - 배송비
  4. 쿠폰/적립금 복구 안내: 사용했던 쿠폰/적립금 자동 복구됨 명시
  5. 대안 제시: 반품 불가 시 교환, 중고 거래 등 대안 안내
  6. 패스트박스 검수: 회수 후 검수 과정이 있음을 안내

반품 조건 체크리스트​

항목조건확인 방법
수령일7일 이내배송 완료일 기준 계산

착용 흔적없음사진 요청 또는 패스트박스 회수 시 확인
세탁X고객 확인
포장 상태원상태 유지패스트박스 회수 시 확인

환불 금액 계산 예시​

예시: SNYDER WIDE DENIM 반품
결제 금액: 180,000원
