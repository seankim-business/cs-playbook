환불 처리 절차 문의

1. 상황 설명​

고객이 반품/취소 후 환불이 언제 처리되는지, 환불 상태를 확인하거나, 환불이 지연되고 있다고 문의합니다.

주요 패턴:

  • "반품했는데 환불 언제 돼요?"
  • "주문 취소했는데 돈이 아직 안 들어왔어요"
  • "카드 취소 기간이 얼마나 걸려요?"
  • "환불 요청한 지 일주일 됐는데 아직이에요"
  • "무통장입금으로 결제했는데 환불 어떻게 되나요?"

2. 에이전트 행동 플로우​

  1. 주문 정보 확인

    • 고객명 확인 ({{고객명}} 고객님 호칭 사용)
    • 주문번호 확인 (없으면 요청)
    • 결제 수단 확인 (카드/무통장/페이)
    • 반품/취소 접수일 확인
    • 검수 완료 여부 확인
    • 최근 구매/이전 불편 이력 확인 ({{최근_구매_이력}}, {{이전_불편_이력}})

  2. 환불 상태 분류

    • 취소 → 환불 대기: 결제 취소 처리 진행 중
    • 반품 → 검수 중: 상품 회수 후 검수 진행 중
    • 반품 → 검수 완료 → 환불 처리 중: 검수 통과 후 환불 처리 중
    • 환불 완료: 이미 처리 완료 (카드사 반영 대기)

  3. 결제 수단별 환불 기간 안내

결제 수단환불 소요 기간비고
신용카드영업일 3-7일카드사별 상이
체크카드영업일 3-7일은행별 상이
무통장입금/계좌이체영업일 1-3일환불 계좌 확인 필요
네이버페이즉시~영업일 3일네이버페이 잔액 반환
카카오페이즉시~영업일 3일카카오페이 잔액 반환
  1. 환불 지연 대응
    • 10일 이상 미처리: 즉시 확인 + 사과 쿠폰(3,000원) 발급
    • 카드사 반영 지연: 카드사 직접 문의 안내 (결제 취소 접수 확인서 제공)
    • 무통장 환불 계좌 미확인: 고객에게 환불 계좌 요청

3. 응답 템플릿​

3a. 일반 환불 안내 (ChannelTalk)​

"{{고객명}} 고객님, 환불 일정 기다리시느라 답답하셨을 것 같아 먼저 안내드려요. 현재 주문건은 [상태]이고, [결제수단] 기준 영업일 [기간] 내 환불 예정입니다. {{최근_구매_이력}}까지 함께 확인했고 변동 생기면 ChannelTalk으로 바로 말씀드릴게요."

3b. 환불 지연 케이스 (ChannelTalk)​

"{{고객명}} 고객님, 환불 지연으로 많이 답답하셨을 것 같아요ㅠㅠ 먼저 죄송합니다. 현재 [지연_사유_요약] 단계이고, 변명 아닌 진행상황 공유 기준으로 필요한 내용만 안내드릴게요. 주문번호 확인 후 정책 기준 처리 단계와 예상 완료 시점을 [후속_시간] 내 다시 안내드리겠습니다. {{이전_불편_이력}}도 같이 보고 우선 확인 건으로 잡아두겠습니다."

3c. 무통장 환불 계좌 요청 (ChannelTalk)​

"{{고객명}} 고객님, 환불을 바로 진행하려면 계좌 정보(은행명/계좌번호/예금주)가 필요해요. 정보 확인 즉시 영업일 [기간] 기준으로 입금 처리하겠습니다. 계좌 받는 즉시 완료 예정 시점까지 ChannelTalk으로 이어서 안내드릴게요."

3d. 이메일 응답​

안녕하세요, 2000 아카이브입니다.

환불 처리 관련 문의 주신 내용 확인했습니다.
{{고객명}} 고객님의 최근 주문 이력({{최근_구매_이력}})과 이전 불편 이력({{이전_불편_이력}})도 함께 확인해 안내드립니다.

고객님의 주문건(주문번호: [번호])은 현재 [검수 완료/환불 처리 중] 상태이며,
[결제 수단]으로 영업일 [기간] 내에 환불 처리됩니다.

추가 궁금하신 사항 있으시면 언제든 문의 부탁드립니다.

감사합니다.

4. 에스컬레이션 조건​

상황에스컬레이션 레벨
환불 금액 50,000원 초과매니저 확인 필요
환불 지연 10일 이상운영팀 에스컬레이션
부분 환불 분쟁 (금액 불일치)매니저 에스컬레이션
고객 3회 이상 재문의즉시 매니저 에스컬레이션

5. 자주 발생하는 이슈​

5a. 부분 반품 시 환불 금액​

  • 쿠폰 적용된 주문의 부분 반품 시 환불 금액 재계산 필요
  • 참조: 10_06_coupon_point_promo_policy.md 부분 반품 예시

5b. 무신사 환불​

  • 무신사 주문건은 무신사 파트너센터에서 환불 처리
  • 무신사 환불 기간: 검수 완료 후 영업일 3-5일
  • 무신사 환불 지연 시 무신사 CS에 먼저 문의 안내

5c. 29CM 환불​

  • 29CM 주문건은 29CM 판매자센터에서 환불 처리
  • 환불 기간: 검수 완료 후 영업일 3-5일

6. 주의사항​

  • 카드 취소 시점과 카드사 반영 시점이 다를 수 있으므로 “취소 접수 완료”와 “실제 반영 예정일”을 분리해 안내합니다.
  • 환불 지연 고객에게는 사과 문구 + 현재 처리 단계 + 예상 완료 시점을 함께 제공합니다.
  • 무통장 환불은 계좌 정보 오기재가 잦으므로 은행명/계좌번호/예금주를 반드시 재확인합니다.
  • 환불 안내에 {{최근_구매_이력}}, {{이전_불편_이력}} 확인 문장을 1줄 포함합니다.
  • 환불 지연/항의 첫 응답은 이모지 없이(필요 시 ㅠㅠ 1회) 공감 → 사과 → 현재 단계 → 후속 시점 순서로 작성합니다.
