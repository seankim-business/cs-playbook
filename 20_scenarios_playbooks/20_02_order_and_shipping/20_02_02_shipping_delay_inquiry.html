배송 지연 문의

1. 상황 설명​

고객이 주문한 상품이 예상 도착일보다 늦게 도착하거나, 배송 추적이 업데이트되지 않아 문의합니다.

주요 패턴:

  • "SNYDER WIDE DENIM 주문한 지 일주일 됐는데 아직 안 와요"
  • "배송 조회가 며칠째 그대로인데 어떻게 된 건가요?"
  • "NAPOLEON JACKET 배송 예정일이 지났는데 아직 안 왔어요"
  • "키링은 같이 안 오나요? 데님만 왔어요"

2. 에이전트 행동 플로우​

  1. 주문 정보 확인

    • 고객명 확인 ({{고객명}} 고객님 호칭 사용)
    • 주문번호 확인 (없으면 요청)
    • 자사몰: Cafe24 어드민에서 주문/송장 상태 조회
    • 무신사/29CM: 해당 플랫폼에서 배송 상태 확인
    • 패스트박스 3PL 시스템에서 출고 상태 확인
    • 최근 구매/이전 불편 이력 확인 ({{최근_구매_이력}}, {{이전_불편_이력}})

  2. 배송 상태 분석

    • 송장번호 확인
    • 택배사 추적 시스템 연동하여 현재 위치 파악
    • 마지막 업데이트 시간 확인

  3. 지연 원인 파악 -- Known Issues 우선 확인

    • 셀릭 ERP 상품코드 매칭 오류: 셀릭 전환 중(2026-02) 상품코드 불일치로 출고 지연 발생
    • 패스트박스 연휴 물량 적체: 설 연휴(2/1-2/4 택배 휴무) 후 물량 적체로 출고 순서 지연
    • SNYDER WIDE DENIM 키링 누락: 데님 구매 시 사은품 키링이 별도 발송 또는 누락되는 이슈
    • 정상 범위: 영업일 기준 3-5일 이내 → 정상 진행 중 안내
    • 배송 사고: 분실/파손 의심 시 → 택배사 조사 의뢰

  4. 응답 작성

    • 현재 배송 위치 안내
    • 예상 도착일 안내 (정확한 날짜 단정 금지)
    • 지연 원인 설명 (Known Issues 매칭)
    • 보상 정책 안내 (해당 시)

  5. 후속 조치

    • 배송 사고 의심 시 택배사 조사 의뢰 + 재발송 준비
    • 장기 지연 시 보상 검토 (쿠폰, 부분 환불 등)

4. 주의사항​

절대 금지 표현​

  • "택배사 문제라 저희는 어쩔 수 없습니다" -- 책임 회피 금지
  • "원래 이 정도 걸립니다" (고객 불만 무시)
  • "정확한 도착일은 모릅니다" (대신 "~경 도착 예상")
  • "ERP 전환 중이라 어쩔 수 없어요" -- 내부 사정 노출 최소화

권장 표현​

  • "택배사에 확인 중이며, 확인 즉시 안내드리겠습니다"
  • "배송 지연으로 불편을 드려 죄송합니다"
  • "{{날짜}}경 도착 예상됩니다"
  • "물류 처리에 다소 지연이 발생하고 있습니다" (ERP 전환 대신)

추가 주의사항​

  1. 실시간 추적 확인: 응답 전 반드시 Cafe24 어드민 + 패스트박스 시스템에서 최신 상태 확인
  2. Known Issues 매칭: 25_known_issues_current/ 폴더에서 현재 활성 이슈 확인
  3. 보상 기준 명확히: 지연 기간에 따라 보상 수준 차등
  4. 배송 사고 신속 대응: 추적 중단 3일 이상 시 즉시 조사 의뢰
  5. 고객 불안 해소: "확인 중", "조사 중" 등 진행 상황 명확히 안내
  6. 이력 반영: 지연/누락/사고 안내 시 {{최근_구매_이력}}, {{이전_불편_이력}}를 한 줄 반영
  7. 감정 고조 톤: 지연 항의 첫 응답은 이모지 없이(필요 시 ㅠㅠ 1회) 공감/사과/예상 시점/후속 약속 순서 유지

지연 유형별 대응​

지연 유형대응
정상 범위 (3-5일)정상 진행 중 안내

심각한 지연 (8일+)원인 설명 + 보상 (쿠폰 5,000원)
배송 사고 의심 (추적 중단 3일+)택배사 조사 의뢰 + 재발송 준비
