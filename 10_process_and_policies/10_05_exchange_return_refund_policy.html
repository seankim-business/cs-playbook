교환/반품/환불 정책

기본 원칙​

2000 아카이브스는 전자상거래법에 따라 고객의 교환/반품 권리를 보장합니다.

핵심 규칙​

  • 교환/반품 가능 기간: 상품 수령 후 7일 이내
  • 단순변심 반품 배송비: 편도 3,000원 (고객 부담)
  • 불량/오배송 시 배송비: 무료 (회사 부담)

교환 정책​

교환 가능 조건​

조건세부 사항
기간상품 수령 후 7일 이내 접수
상품 상태미착용, 택 부착, 세탁하지 않은 상태
사유단순변심(사이즈/색상), 불량, 오배송

교환 절차​

1. 고객센터 접수
   - 채널톡, 이메일, 마이페이지
   - 교환 사유, 희망 사이즈/색상 명시
   ↓
2. 교환 접수 완료
   - CS 담당자가 교환 가능 여부 확인
   - 교환 상품 재고 확인
   ↓
3. 상품 수거
   - 택배사 방문 수거 (일정 조율)
   - 또는 고객이 직접 발송
   ↓
4. 검수
   - 상품 도착 후 상태 확인 (1-2일 소요)
   - 교환 가능 여부 최종 판단
   ↓
5. 교환 상품 재발송
   - 검수 통과 시 즉시 재발송
   - 송장 번호 SMS/이메일 발송

총 소요 기간: 약 5-7일 (수거 → 검수 → 재발송)

교환 배송비​

교환 사유왕복 배송비비고
단순변심 (사이즈/색상)6,000원 (왕복)고객 부담
불량무료회사 부담
오배송 (잘못된 상품 발송)무료회사 부담

결제 방법: 교환 상품 발송 시 배송비 동봉 (착불) 또는 계좌 입금

교환 불가 사유​

다음 경우 교환이 불가능합니다.

사유설명
착용 흔적땀 냄새, 화장품 자국, 변형 등
택 제거상품 택, 라벨이 제거되거나 훼손된 경우
세탁세탁, 수선한 경우
향수향수, 방향제 등 강한 냄새가 배인 경우
7일 초과수령 후 7일이 지난 경우
재고 소진교환 희망 사이즈/색상 재고 없음 (환불 전환 가능)

검수 불합격 시:

  • 고객에게 사유 안내
  • 상품 재반송 (배송비 고객 부담)
  • 환불 전환 옵션 제공

반품 정책​

반품 가능 조건​

교환과 동일 (상품 수령 후 7일 이내, 미착용, 택 부착)

반품 절차​

1. 고객센터 접수
   - 반품 사유 명시
   ↓
2. 반품 접수 완료
   - 환불 계좌 정보 확인
   ↓
3. 상품 수거
   - 택배사 방문 수거 또는 고객 직접 발송
   ↓
4. 검수
   - 상품 도착 후 상태 확인 (1-2일)
   ↓
5. 환불 처리
   - 검수 통과 시 즉시 환불
   - 결제 수단별 환불 소요 기간 상이

총 소요 기간: 약 5-10일 (수거 → 검수 → 환불 완료)

반품 배송비​

반품 사유배송비비고
단순변심3,000원 (편도)고객 부담
불량무료회사 부담 (왕복 무료)
오배송무료회사 부담 (왕복 무료)

결제 방법:

  • 고객이 직접 발송 시: 착불 발송
  • 택배사 수거 시: 환불액에서 차감

환불 정책​

환불 방법​

결제 수단환불 방식소요 기간
신용카드/체크카드결제 승인 취소3-7영업일
계좌이체고객 계좌 입금1-3영업일
무통장입금고객 계좌 입금1-3영업일
네이버페이네이버페이 머니 환급즉시-3영업일
카카오페이카카오머니 환급즉시-3영업일

참고: 환불 소요 기간은 검수 완료 후 기준

환불액 계산​

예시 1: 단순 반품 (쿠폰 없음)​

주문 금액: 50,000원
배송비: 무료 (5만원 이상)
반품 배송비: -3,000원

환불액: 50,000 - 3,000 = 47,000원

예시 2: 쿠폰 사용 주문 반품​

주문 금액: 50,000원
쿠폰 할인: -5,000원
최종 결제: 45,000원

반품 배송비: -3,000원
환불액: 45,000 - 3,000 = 42,000원

참고: 쿠폰은 반품 시 복구되지 않음 (쿠폰 정책에 따라 예외 가능)

예시 3: 불량품 반품 (무료)​

주문 금액: 30,000원
배송비: 3,000원 (5만원 미만)
총 결제: 33,000원

불량 반품 → 배송비 무료
환불액: 33,000원 (배송비 포함 전액 환불)

부분 교환/반품​

부분 교환​

  • 가능 조건: 2개 이상 주문 시, 일부만 교환 가능
  • 배송비: 교환 상품에 대해서만 배송비 부과
  • 나머지 상품: 그대로 보유

예시:

주문: A 상품 + B 상품
교환: A 상품만 교환 (사이즈 변경)
→ A 상품 교환 배송비 6,000원 부담
→ B 상품은 그대로 보유

부분 반품​

  • 가능 조건: 2개 이상 주문 시, 일부만 반품 가능
  • 배송비 재계산: 남은 상품 금액이 5만원 미만이면 배송비 추가 차감

예시:

주문 내역:
- A 상품: 40,000원
- B 상품: 20,000원
- 배송비: 무료 (총 60,000원)

부분 반품: B 상품 (20,000원)
→ 남은 금액: 40,000원 (무료배송 조건 미달)
→ 배송비 3,000원 추가 차감
→ 환불액: 20,000 - 3,000 - 3,000(반품 배송비) = 14,000원

불량품 & 오배송 처리​

불량품 기준​

불량 유형예시
제작 불량봉제 터짐, 단추 빠짐, 지퍼 고장 등
오염얼룩, 이물질, 손상 등
색상 불량상세 페이지와 현저히 다른 색상
사이즈 오차실측 사이즈와 2cm 이상 차이

불량 판단 기준: 입고 또는 착용이 불가능한 수준

불량품 처리 절차​

1. 고객센터 접수
   - 불량 사진 첨부 (필수)
   - 불량 부위 상세 설명
   ↓
2. 불량 확인
   - CS 담당자가 사진 검토
   - 불량 인정 시 즉시 교환/환불 진행
   ↓
3. 수거 & 재발송
   - 택배사 무료 수거
   - 교환 상품 즉시 발송 (검수 생략 가능)
   ↓
4. 보상
   - 5,000원 쿠폰 발급 (불편 사과)

소요 기간: 2-3일 (일반 교환보다 빠름)

오배송 처리​

  • 정의: 주문한 상품과 다른 상품이 배송된 경우
  • 처리: 불량품과 동일 (무료 교환 + 5,000원 쿠폰)
  • 책임: 회사 측 실수이므로 모든 비용 회사 부담

교환/반품 관련 주요 문의 & 응대​

1. 사이즈 교환​

고객: "사이즈가 안 맞아요. 교환 가능한가요?"

CS 응답:

"네, 가능합니다. 수령 후 7일 이내이고 미착용 상태라면 교환 가능합니다.

  • 희망 사이즈: [고객에게 확인]
  • 교환 배송비: 6,000원 (왕복)
  • 소요 기간: 5-7일

교환 접수를 도와드릴까요?"

2. 색상 불만​

고객: "사진이랑 색이 너무 달라요"

CS 응답:

  1. 주관적 색상 차이 (모니터, 조명 등):

    "촬영 환경과 모니터 설정에 따라 실제 색상과 차이가 있을 수 있습니다. 수령 후 7일 이내라면 반품 가능하며, 단순변심 반품 배송비 3,000원이 부과됩니다."

  2. 명백한 색상 불량 (현저히 다른 경우):

    "확인해보니 색상 차이가 크네요. 불량으로 처리하여 무료 교환 또는 전액 환불해드리겠습니다. 추가로 불편에 대한 사과로 5,000원 쿠폰을 발급해드리겠습니다."

3. 반품 후 환불 지연​

고객: "반품한 지 10일이 지났는데 환불이 안 됐어요"

CS 응답:

  1. 상품 도착 여부 확인
  2. 검수 상태 확인
  3. 환불 처리 상태 확인

CS 응답 예시:

"확인해보니 고객님의 상품은 [날짜]에 도착하여 검수를 완료했습니다. 환불은 [날짜]에 처리되었으며, 카드사 사정에 따라 3-7영업일 내 환불됩니다. 현재 [X일] 경과했으므로 곧 확인하실 수 있을 것 같습니다."

4. 택 제거 후 교환 요청​

고객: "택을 떼어버렸는데 교환 가능한가요?"

CS 응답:

"죄송하지만 택이 제거된 경우 교환/반품이 어렵습니다. 전자상거래법에 따라 상품의 가치가 훼손된 경우 교환/반품이 제한됩니다. 양해 부탁드립니다."

예외: 불량품인 경우 택 제거 여부와 관계없이 교환 가능

교환/반품 에스컬레이션​

즉시 에스컬레이션 필요 상황​

상황에스컬레이션 대상조치
검수 불합격 이의 제기관리자재검수 또는 사진 증거 요청
불량 여부 애매한 경우품질팀전문가 검토
10만원 이상 환불매니저 승인승인 후 처리
고객 과도한 요구관리자정책 기준 재안내

SOP 참조: 주문 취소/교환/환불 처리​

원본 문서: Notion - 주문 취소/교환/환불 처리 SOP 최종 동기화: 2026-02-15 담당자: 솔 Sol (Accountable) 상태: 진행 중 (Doing)

적용 범위​

  • ✅ 2000Archives 자사몰 + 무신사/29CM 등 플랫폼 주문 전체
  • ✅ 취소 (출고 전), 교환 (사이즈/불량), 환불 (반품 후 환불)
  • ❌ 아뜰리에 B2B 프로젝트 → 별도 클라이언트 계약 조건 참조
  • ❌ 단순 문의 (배송 조회 등) → CS 일반 응대 참조

SOP 프로세스 요약​

Step 1: 요청 접수 및 유형 분류

  • [CS 담당자]가 고객 요청을 접수한다 (자사몰 게시판, 카카오톡, 플랫폼 CS)
  • 요청 유형 분류:
    • 취소: 출고 전 단순 변심 → Step 2A
    • 교환: 사이즈 교환 또는 불량 교환 → Step 2B
    • 환불: 반품 후 환불 → Step 2C
  • WHY: 유형별로 프로세스가 다르므로 초기 분류가 정확해야 처리 시간을 단축할 수 있다
  • 완료 조건: 요청 유형 분류 완료, 고객에게 접수 확인 안내

Step 2A: 취소 처리 (출고 전)

  • 주문 상태가 출고 전인지 확인
  • 출고 전이면 즉시 주문 취소 처리 → 결제 수단에 따라 환불 진행
  • 출고 후이면 → Step 2C(환불)로 전환
  • 완료 조건: 취소 완료 + 환불 시작

Step 2B: 교환 처리

  • 교환 사유 확인 (사이즈 / 불량 / 오배송)
  • 재고 확인 → 교환 가능 여부 판단:
    • 교환 재고 있음 → 반품 수거 + 교환 상품 출고
    • 교환 재고 없음 → 고객에게 안내 → 환불 전환 또는 대기
    • 불량 → 사진 확보 + 불량 리포트 작성 → 교환 or 환불
  • 완료 조건: 교환 상품 출고 또는 환불 전환 완료

Step 2C: 환불 처리 (반품)

  • 반품 수거 접수 (자사몰: 직접 수거 / 플랫폼: 플랫폼 반품 절차)
  • 반품 상품 입고 후 상태 검수:
    • 상태 양호 → 환불 승인 + 재고 복원
    • 착용/세탁 흔적 → 환불 거부 or 부분 환불 (고객 안내)
    • 불량 확인 → 전액 환불 + 불량 리포트
  • 환불 금액 정산: 결제 수단에 따라 3~7영업일 이내 환불
  • 완료 조건: 환불 완료 + 재고 반영

Step 3: 데이터 기록 및 리포트

  • 처리 완료 건을 CS 트래킹 시트에 기록
  • 취소/교환/환불 사유를 분류하여 월간 CS 리포트에 반영
  • WHY: 사유 분석을 통해 반복 문제(사이즈 가이드 부정확, 특정 SKU 불량률 등)를 파악하고 개선

트러블슈팅​

Q: 플랫폼 반품 수거가 지연된다 A: 플랫폼 CS에 수거 독촉 → 3영업일 이상 지연 시 고객에게 직접 수거 안내

Q: 고객이 환불 거부에 불만을 표시한다 A: 거부 사유를 사진과 함께 명확히 안내 → 부분 환불 제안 → 그래도 불만 시 PM 에스컬레이션
