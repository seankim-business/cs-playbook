쿠폰/포인트/프로모션 정책

쿠폰 정책​

쿠폰 유형​

쿠폰 유형발급 조건할인율/금액유효 기간
신규가입 쿠폰회원 가입 시 자동 발급5,000원발급일로부터 30일
생일 쿠폰생일 월 1일 자동 발급10% 할인 (최대 1만원)생일 월 말일까지
시즌 할인 쿠폰시즌 프로모션 기간10-20% 할인프로모션 종료일까지
VIP 쿠폰VIP 등급 고객에게 분기별15% 할인 (최대 3만원)발급일로부터 60일
보상 쿠폰불량/지연/오배송 사과3,000-10,000원발급일로부터 90일
이벤트 쿠폰특정 이벤트 참여이벤트별 상이이벤트 종료일까지

쿠폰 사용 규칙​

기본 사용 조건​

  • 최소 주문 금액: 쿠폰별 상이 (일반적으로 3만원 이상)
  • 중복 사용: 불가 (1회 주문당 1개 쿠폰만 사용 가능)
  • 적용 대상: 특정 쿠폰은 세일 상품 제외 (쿠폰 설명 참조)

쿠폰 적용 우선순위​

다중 쿠폰 보유 시, 고객이 가장 유리한 쿠폰을 선택할 수 있도록 시스템이 자동 계산하여 추천합니다.

예시:

보유 쿠폰:
1. 5,000원 할인 쿠폰
2. 10% 할인 쿠폰

주문 금액: 60,000원

선택 1: 5,000원 쿠폰 → 최종 55,000원
선택 2: 10% 쿠폰 → 최종 54,000원

→ 시스템 추천: "10% 할인 쿠폰이 더 유리합니다"

쿠폰 만료 안내​

자동 안내​

  • 만료 7일 전: SMS/이메일 자동 발송
  • 만료 1일 전: 푸시 알림 발송

만료된 쿠폰​

  • 복구 불가: 만료된 쿠폰은 재발급되지 않음
  • 예외: VIP 고객 또는 특별한 사유가 있는 경우, 관리자 승인 하에 재발급 가능

고객 문의 시 응답:

"죄송하지만 만료된 쿠폰은 재발급이 어렵습니다. 다만, 현재 진행 중인 프로모션이 있으니 확인해보시겠어요?"

쿠폰 취소/환불 시 처리​

상황쿠폰 복구 여부비고
주문 취소 (발송 전)✅ 자동 복구유효 기간 내 재사용 가능
교환✅ 복구쿠폰 그대로 유지
반품 (전체)❌ 복구 불가쿠폰 소멸
부분 반품⚠️ 재계산남은 금액에 맞춰 할인 재계산

부분 반품 예시:

주문 내역:
- A 상품: 50,000원
- B 상품: 30,000원
- 10% 쿠폰 적용: -8,000원
= 총 72,000원

부분 반품: B 상품 (30,000원)
→ 쿠폰 재계산: 50,000 × 10% = -5,000원
→ A 상품 최종: 45,000원
→ 환불액: 72,000 - 45,000 = 27,000원

쿠폰은 소멸 (재사용 불가)

포인트 정책​

포인트 적립​

적립 조건적립률비고
일반 구매구매 금액의 1%배송 완료 후 적립
VIP 고객구매 금액의 3%VIP 등급 혜택
리뷰 작성500포인트포토 리뷰 1,000포인트
이벤트 참여이벤트별 상이프로모션 기간

포인트 사용 규칙​

기본 사용 조건​

  • 최소 적립 금액: 1,000포인트 이상 적립 시 사용 가능
  • 사용 단위: 100포인트 단위로 사용
  • 최대 사용 한도: 주문 금액의 50%까지 (VIP는 70%)
  • 쿠폰과 중복 사용: 가능 (포인트는 쿠폰과 별개)

예시:

주문 금액: 50,000원
쿠폰 적용: -5,000원
포인트 사용: -2,000포인트 (2,000원)
최종 결제: 43,000원

포인트 유효 기간​

  • 기본: 적립일로부터 1년
  • 소멸 예정 안내: 소멸 30일 전 SMS/이메일 발송

고객 문의 시 응답:

"고객님의 포인트 [X,XXX포인트]는 [날짜]에 소멸 예정입니다. 해당 기간 내에 사용하시면 됩니다."

포인트 취소/환불 시 처리​

상황포인트 처리
주문 취소 (발송 전)사용한 포인트 자동 복구
교환포인트 변동 없음
반품사용한 포인트 자동 복구 + 적립 포인트 차감

반품 예시:

구매 시:
- 결제 금액: 50,000원
- 포인트 적립: +500포인트

반품 시:
- 적립 포인트 차감: -500포인트
- 사용한 포인트 복구 (있을 경우)

프로모션 정책​

프로모션 유형​

프로모션 유형설명예시
시즌 세일봄/여름/가을/겨울 시즌 할인"SS 시즌 20% 할인"
특가전특정 상품 한정 할인"베스트셀러 30% 할인"
1+1 이벤트상품 구매 시 증정품 제공"티셔츠 구매 시 양말 증정"
타임세일특정 시간대 한정 할인"오늘 18시-21시 30% 할인"
무료배송 이벤트조건 없이 무료배송"이번 주 전 상품 무료배송"

프로모션 중복 할인 불가 원칙​

기본 원칙: 프로모션 할인 + 쿠폰 할인 중복 불가

예외: 포인트는 중복 사용 가능

적용 항목중복 가능 여부
프로모션 할인 + 쿠폰❌ 불가
프로모션 할인 + 포인트✅ 가능
쿠폰 + 포인트✅ 가능

예시:

상품 원가: 50,000원
시즌 세일: 20% 할인 (40,000원)

선택 1: 프로모션 할인만 적용 → 40,000원
선택 2: 쿠폰 5,000원만 적용 → 45,000원

→ 프로모션 할인이 더 유리하므로, 쿠폰 사용 불가 안내

고객 응대:

"죄송하지만 프로모션 할인이 적용된 상품은 쿠폰을 중복 사용할 수 없습니다. 현재 프로모션 할인(20%)이 더 유리하시므로 그대로 진행하시는 것을 추천드립니다."

프로모션 종료 후 주문 취소​

원칙: 프로모션 종료 후 취소 시, 재주문 시 정가 적용

예시:

프로모션 기간: 2/10-2/14
고객 주문: 2/12 (20% 할인 적용)
고객 취소: 2/20 (프로모션 종료 후)

→ 재주문 시 정가 적용 (프로모션 복구 불가)

고객 응대:

"죄송하지만 취소 시점이 프로모션 종료 후이므로, 재주문 시에는 정가가 적용됩니다. 현재 진행 중인 다른 프로모션이 있는지 확인해드릴까요?"

쿠폰/포인트/프로모션 주요 문의 & 응대​

1. 쿠폰이 적용 안 돼요​

고객: "쿠폰을 입력했는데 할인이 안 돼요"

원인 체크리스트:

  • 최소 주문 금액 미달
  • 세일 상품 제외 쿠폰인데 세일 상품 구매
  • 유효 기간 만료
  • 이미 사용한 쿠폰

CS 응답:

"쿠폰 적용이 안 되는 이유를 확인해보니 [원인]입니다. [해결 방법]으로 진행하시면 적용 가능합니다."

2. 포인트가 적립 안 됐어요​

고객: "주문한 지 일주일 지났는데 포인트가 안 들어왔어요"

CS 응답:

"포인트는 배송 완료 후 적립됩니다. 현재 고객님의 주문 상태를 확인해보니 [상태]입니다. 배송 완료 후 익일 자동 적립될 예정입니다."

3. 여러 쿠폰을 같이 쓸 수 없나요?​

고객: "5,000원 쿠폰이랑 10% 쿠폰 둘 다 쓰고 싶어요"

CS 응답:

"죄송하지만 1회 주문당 1개의 쿠폰만 사용 가능합니다. 고객님의 경우 [금액 계산]을 해보니 [더 유리한 쿠폰]을 사용하시는 것이 좋을 것 같습니다."

4. 만료된 쿠폰 재발급 요청​

고객: "쿠폰이 어제 만료됐는데 다시 발급해주실 수 있나요?"

CS 응답:

  • 일반 고객: "죄송하지만 만료된 쿠폰은 재발급이 어렵습니다."
  • VIP 고객: "VIP 고객님이시니 특별히 동일한 쿠폰을 재발급해드리겠습니다." (관리자 승인 필요)

5. 포인트를 전액 사용하고 싶어요​

고객: "포인트가 5,000포인트 있는데 전부 쓸 수 없나요?"

CS 응답:

"포인트는 주문 금액의 최대 50%까지 사용 가능합니다. 고객님의 주문 금액이 [X원]이므로, 최대 [Y포인트]까지 사용하실 수 있습니다."

쿠폰 발급 권한​

CS 담당자 발급 권한​

쿠폰 금액발급 권한승인 필요
3,000원 이하담당자 단독 발급 가능불필요
5,000원담당자 발급 가능 (기록 필수)불필요
10,000원 이상매니저 승인 필요필수

발급 사유 예시:

  • 불량품 사과: 5,000원
  • 배송 지연 사과: 3,000원
  • 오배송 사과: 5,000원
  • 심각한 서비스 오류: 10,000원 (매니저 승인)
