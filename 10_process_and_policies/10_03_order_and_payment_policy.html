주문 & 결제 정책

주문 프로세스​

일반 주문 흐름​

1. 장바구니 담기
   ↓
2. 주문서 작성 (배송지, 결제 정보)
   ↓
3. 결제
   ↓
4. 주문 접수 (자동 확인 이메일 발송)
   ↓
5. 상품 준비
   ↓
6. 배송 출발 (송장 번호 발송)
   ↓
7. 배송 완료

주문 변경 정책​

주문 변경/취소 가능 기준​

주문 상태변경 가능 항목조치 방법
결제 완료전체 취소, 배송지 변경, 상품 변경고객센터 또는 마이페이지
상품 준비 중배송지 변경, 부분 취소고객센터 문의 (시간 제한 있음)
배송 준비 중배송지 변경만 가능즉시 고객센터 문의 (익일 발송 전까지)
배송 중변경 불가수령 후 교환/반품
배송 완료변경 불가교환/반품만 가능

주문 취소 규칙​

전체 취소​

  • 가능 시점: 배송 출발 전까지
  • 처리 시간: 즉시 취소 (결제 승인 취소)
  • 환불 소요 기간: 결제 수단별 상이 (아래 표 참조)

부분 취소​

  • 가능 조건: 2개 이상 상품 주문 시, 일부만 취소 가능
  • 제약 사항:
    • 묶음 배송 상품은 부분 취소 시 배송비 재계산
    • 쿠폰 적용 주문은 부분 취소 시 쿠폰 재계산 (할인 비율 조정)
  • 예시: 
    주문 내역: A 상품 50,000원 + B 상품 30,000원 = 80,000원
    쿠폰: 10% 할인 (-8,000원) → 최종 72,000원

    부분 취소: B 상품 취소
    → 할인 재계산: A 상품 50,000원 - 10% = 45,000원
    → 환불액: 72,000 - 45,000 = 27,000원

배송지 변경​

  • 가능 시점: 배송 출발 전까지
  • 변경 방법:
    1. 마이페이지 > 주문 내역 > 배송지 변경 (자동 처리)
    2. 고객센터 문의 (수동 처리)
  • 주의 사항:
    • 배송 출발 후에는 택배사 측에서 변경 불가
    • 긴급 변경 시 고객센터로 전화 문의 권장

결제 수단 & 환불 정책​

지원 결제 수단​

결제 수단지원 여부비고
신용카드✅ 지원국내 모든 카드사
체크카드✅ 지원국내 모든 카드사
계좌이체✅ 지원실시간 계좌이체
무통장입금✅ 지원입금 확인 후 배송
네이버페이✅ 지원포인트 사용 가능
카카오페이✅ 지원머니 사용 가능
토스페이✅ 지원-
페이코⚠️ Phase 2준비 중
해외카드❌ 미지원추후 지원 예정

결제 수단별 환불 소요 기간​

결제 수단환불 방식소요 기간비고
신용카드결제 승인 취소3-7영업일카드사별 차이 있음
체크카드결제 승인 취소3-7영업일카드사별 차이 있음
계좌이체고객 계좌 입금1-3영업일계좌 정보 확인 필요
무통장입금고객 계좌 입금1-3영업일입금자명 일치 확인
네이버페이네이버페이 머니 환급즉시-3영업일네이버페이 정책 따름
카카오페이카카오머니 환급즉시-3영업일카카오페이 정책 따름

참고: 영업일 기준이며, 주말/공휴일 제외

환불 지연 시 대응​

예상 소요 기간 초과 시조치
카드 결제: 7일 초과PG사(결제대행사)에 문의하여 처리 상태 확인
계좌이체: 3일 초과고객 계좌번호 재확인 후 재송금
간편결제: 3일 초과해당 결제사(네이버/카카오)에 문의

중복 결제 & 결제 오류 처리​

중복 결제​

  • 발생 원인: 네트워크 오류, 새로고침, 중복 클릭 등
  • 확인 방법: 주문 내역 2건 이상 생성 여부 확인
  • 처리 절차:
    1. 즉시 중복 주문 전체 취소 처리
    2. 결제 승인 취소 (자동 환불)
    3. 고객에게 취소 완료 안내 + 환불 예정일 안내

고객 응대 예시:

"중복 결제가 확인되어 즉시 취소 처리했습니다. 결제 승인 취소가 완료되었으며, 카드사에 따라 3-7영업일 내 환불됩니다. 불편을 드려 죄송합니다."

결제 실패​

  • 발생 원인: 카드 한도 초과, 비밀번호 오류, 시스템 오류 등
  • 처리 절차:
    1. 고객에게 결제 실패 사유 안내
    2. 재결제 안내 (다른 결제 수단 제안)
    3. 시스템 오류 시 개발팀 즉시 에스컬레이션

고객 응대 예시:

"결제 승인이 실패했습니다. 카드사에서 [사유: 한도 초과/비밀번호 오류 등]로 승인 거부되었습니다. 다른 결제 수단으로 재시도해 주시거나, 카드사에 문의하시면 도움을 받으실 수 있습니다."

부분 취소 & 환불 계산​

부분 취소 시 환불액 계산 예시​

예시 1: 단순 부분 취소 (쿠폰 없음)​

주문 내역:
- A 상품: 50,000원
- B 상품: 30,000원
- 배송비: 3,000원
= 총 83,000원

부분 취소: B 상품 (30,000원)
→ 환불액: 30,000원
→ 배송비: A 상품만 남았으므로 배송비 유지 (3,000원)

예시 2: 쿠폰 적용 주문 부분 취소​

주문 내역:
- A 상품: 50,000원
- B 상품: 30,000원
- 쿠폰 할인: -8,000원 (10% 할인)
= 총 72,000원

부분 취소: B 상품
→ 쿠폰 재계산: 50,000원 × 10% = -5,000원
→ A 상품 최종 금액: 45,000원
→ 환불액: 72,000 - 45,000 = 27,000원

예시 3: 무료배송 조건 미달 시​

주문 내역:
- A 상품: 40,000원
- B 상품: 20,000원
- 배송비: 무료 (5만원 이상 주문)
= 총 60,000원

부분 취소: B 상품 (20,000원)
→ 남은 금액: 40,000원 (무료배송 조건 미달)
→ 배송비 3,000원 추가 부과
→ 환불액: 20,000 - 3,000 = 17,000원

묶음 배송 정책​

묶음 배송 조건​

  • 동일 날짜 주문: 같은 날 여러 건 주문 시 자동 묶음 배송
  • 예약배송 + 일반 배송: 묶음 불가 (별도 발송)
  • 재고 여부: 모든 상품 재고 있을 때만 묶음 가능

묶음 배송 시 배송비​

  • 5만원 이상: 무료 배송
  • 5만원 미만: 3,000원 (1회만 부과)

고객 응대 예시:

"오늘 주문하신 2건(A, B)은 자동으로 묶음 배송됩니다. 총 주문 금액이 6만원이므로 배송비는 무료입니다."

무통장입금 정책​

입금 기한​

  • 기본: 주문 후 2일 이내 (48시간)
  • 기한 초과 시: 자동 주문 취소

입금자명 불일치​

  • 원칙: 입금자명과 주문자명 일치 필요
  • 불일치 시:
    1. 고객에게 연락하여 입금 확인
    2. 입금자명 확인 후 수동 주문 확인 처리

고객 응대 예시:

"입금자명이 주문자명과 다릅니다. 입금하신 분의 성함을 알려주시면 확인 후 주문을 진행하겠습니다."
